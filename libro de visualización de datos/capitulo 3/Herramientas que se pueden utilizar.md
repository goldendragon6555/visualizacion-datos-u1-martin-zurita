[[Contexto general]]

En este capitulo mostrara las herramientas mas comunes para crear visualizaciones de datos e infografía.


### Herramientas de depuración y filtrado
Herramientas útiles para limpiar bases de datos para sacar información de importancia para usarlo ejemplo *Google Refine*
esto nos permite limpiar los datos para sacar los datos no relevante, duplicados o erróneos y tambien que los sirava para trasformar los datos. 

### Herramientas de análisis y exploración

### Herramientas para gráficos de datos
*Google Drive* nos permite crear toda un serie de gráficos dinámicos de forma instantánea, entre los que podemos encontrar: gráficos de barras, gráficos circulares, gráficos geo-posicionados, diagramas de dispersión, gráficos de área, de burbujas, de donut, etc.

### Herramientas para visualización de datos
*Tableau Public* podemos analizar, de forma rápida y sencilla, información cuantitativa mediante el uso de dimensiones y medidas, permitiendo la conexión con bases de datos u hojas de cálculo. 

### Herramientas de visualización de mapas
*Carto DB* permite visualizar datos, de una manera muy sencilla, en función de criterios geográficos. 

### Herramientas para crear infografías
*Picktochaet* es una aplicación web que nos permite crear infografías gratis, a partir de plantillas predefinidas que se puede personalizar y se puede descargar como .png o .jpg.
