[[Contexto del capitulo 2]]

lo importante de crear infografía o una visualización es el valor que le vamos a entregar a los usuarios. para eso tenemos que preguntarnos.
- ¿Cuál es nuestro objetivo de comunicación? ¿Qué queremos lograr?.
- ¿Con quién nos comunicamos o nos debemos comunicar?
- ¿Quiénes son?
- ¿Qué les importa?
- ¿Dónde interactúan?
- ¿Cómo lo hacen?
- ¿A través de qué medio debemos comunicarnos?
- ¿Qué quieres lograr con tus datos y salida gráfica?
con estrás preguntas se pueden hacer la presentación o explicación de la historia o conocimientos que trasmitimos.

### Algunas de las cosas que podemos descubrir con los datos

- *Tendencias*: es el comportamiento de los elementos en entornos no particular durante un tiempo.
- *Patrón*: un elementos que se repiten de una manera predecible.
- *Anomalía*: son elementos que muestran unas condición raras o disfuncionales. 
- *Conexiones*: establecen las relaciones de conexiones entre variables numérica o semántica.
- *Correlaciones*: se considera dos variables cuantitativas están correlacionadas cuando una varia sistemáticamente con la otra.
- *Comparaciones*: comprar dos o mas variables cuantitativa o comparar categorías y comunidad.
- *Geo-localizaciones*: permite visualizar información geo-posicionada.
- *Procesos*: un conjunto de actividades mutuamente relacionadas que interactuar para trasformar elementos de entrada y los convierte en resultado.
