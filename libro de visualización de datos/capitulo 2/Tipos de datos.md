[[Contexto del capitulo 2]]
existen diferentes tipo de datos, que se dividen en dos grandes categorías:
- *Datos cualitativos*: son la que repode a la pregunta "¿cuál?" o "¿cuáles?" son datos que indican color, textura, sentimientos, experiencia, resultados de encuestas...
- *Datos cuantitativos*: son datos responde con números, como: el tamaño, peso, nota ,etc. 

también existen otros tipos de datos
-  *Datos categóricos*: son datos que describe el estado de objeto ("usado", "nuevo", "rota", etc.).
- *Datos discreto*: son datos de números enteros (1,2,3), no puede tener decimales.
- *Datos continuo*: son datos que permiten todo tipos de números.

pero hay dos categorías principales si podemos o no contar los datos
- *Datos nominales*: los datos nominales se basan en etiquetas la información en categorías, como "color de ojo" que se le puede asar un numero, pero seria un código y no se puede sacar el promedio.
- *Datos ordinales*: el dato ordinales, se puede Aser una relación uno a uno entre sus elementos y con los números naturales, dentro de una escala (bajo, medio, alto).
##### Datos estructurados vs datos no estructurados
los datos estructurados son los datos que están ordenado en tablas o campos para que un computador lo entienda, y los datos no estructurados seria el lenguaje natural, imágenes o pdf.
